> **"Plant a Virtual CTO inside every repository so every developer's AI tool follows one shared engineering brain 24/7."**

Welcome to **`Plant-A-Virtual-CTO`**—the central governance, contract, compliance, and AI-context hub for our microservice architecture.

Instead of Agile bureaucracy (daily standups, sprints, story points) or the human CTO having to police every developer's AI prompts manually, **`Plant-A-Virtual-CTO`** plants your architectural standards, Golden Stack rules, API contracts, and SOC 2 / ISO 27001 guardrails directly into every microservice, Angular, and Mobile repository—so **GitHub Copilot, OpenAI Codex, Antigravity, Cursor, and Claude Code** act as extensions of the CTO.

---

## Quickstart Commands

### 1. Plant the Virtual CTO in Any Microservice Repo
```powershell
# Windows PowerShell (set -Stack to "node", "python", "angular", or "mobile")
.\scripts\sync-microservice.ps1 -TargetRepoPath "..\service-a" -Stack "node"
```

### 2. Generate Contract SDKs & Stamp `CONTRACT.lock` (Local or Remote Hub)
```powershell
# From local hub checkout:
.\scripts\generate-sdk.ps1 -TargetRepo "..\service-a" -Stack "node"

# Or fetch directly from remote GitHub Hub without cloning side-by-side:
.\scripts\generate-sdk.ps1 -TargetRepo "." -Stack "node" -RemoteHubUrl "https://github.com/planta94/plant-a-virtual-cto.git"
```

### 3. Export Tamper-Evident SOC 2 & ISO 27001 Audit Evidence Bundle
```powershell
.\scripts\export-audit-evidence.ps1 -Repos @("planta94/service-a", "planta94/service-b", "planta94/plant-a-virtual-cto")
```
