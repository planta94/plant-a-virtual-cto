# GitHub Copilot Repository Instructions (`Plant-A-Virtual-CTO`)

Always read and strictly enforce the Master Technical Handover & AI Constitution in [`AGENTS.md`](../AGENTS.md) at the root of this repository.

## Non-Negotiable Constraints for Copilot
1. **Follow the Golden Stack in `AGENTS.md` (Section 7):**
   - **Node.js / TypeScript:** Strict TypeScript (`noImplicitAny`, no `any`), 3-layer architecture (`Controller -> Service -> Repository`), Prisma/Drizzle ORM, native `fetch` or internal HTTP wrapper, RFC 7807 Problem Details (`application/problem+json`).
   - **Python:** FastAPI, Pydantic v2 (`model_validate`, `ConfigDict(extra="forbid")`), SQLAlchemy 2.0 async, complete type annotations (`mypy --strict`), `ruff` compliance.
   - **Angular:** Standalone components (`standalone: true`), `ChangeDetectionStrategy.OnPush`, Angular Signals (`signal`, `computed`), OpenAPI-generated client services only.
   - **Mobile:** Generated contract models (`ignoreUnknownFields`); hardware-backed encrypted token storage (`Keychain` / `EncryptedSharedPreferences`); zero HTTP or business logic inside UI widgets/screens.
2. **Never Add Unapproved Dependencies:** Do not add new packages to `package.json`, `pyproject.toml`, `requirements.txt`, or `pubspec.yaml` unless explicitly instructed with an `ADR-XXX` reference (or `[CTO-OVERRIDE: reason]`).
3. **Contract-First & `CONTRACT.lock` Integrity:** Never hand-write duplicate API DTOs or manually edit files inside `src/generated/contracts/`. Always regenerate types via `scripts/generate-sdk.ps1` / `.sh` so the SHA-256 `CONTRACT.lock` remains valid.
4. **5-Layer Testing & Anti-Mock Law:** Never mock Prisma, Drizzle, or SQLAlchemy in repository/integration tests (`jest.mock` / `MagicMock` on ORMs is blocked by CI Gate 3). Always include `200` happy path, `400` validation, `401` auth, and `403` cross-tenant IDOR security tests (`>= 85%` diff coverage).
5. **Keep Feature PR Diffs Under 400 Lines:** Target `feature/* -> UAT` in modular, stacked PRs (`< 400 LOC`). Never manually edit `specs/WIP-QUEUE.md` on feature branches (it is auto-generated by GitHub Actions).
